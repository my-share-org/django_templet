This is the audit process. The purpose of the audit process is to find out each and every weak spot of the full project.

When a full audit is initiated, the auditor should that the full project in some criteria and properly document the full audit in a folder which will named with the date and time. When the full audit is initiated inside the folder, only the initial audit report will be generated, and on demand, another file will be created.

The judgment criteria will be:
- Security
- Feature correctness
- Reliability
- Reusability
- Modular coding
- Proper documentation and comments
- Proper testing
- Proper dockerization
- Proper CI/CD pipeline
- Production-grade
- Following best practices

Folder structure:
|-<yyyy-mm-dd_hh-mm>
|   |-00_initial_report
